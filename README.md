# UTS-bolenku
Situs web ini dibuat untuk memenuhi persyaratan tugas akhir mata kuliah basis data tingkat lanjut. Dengan situs web ini, diharapkan data yang semula tidak teratur dari sistem pencatatan manual kini dapat diatur dengan lebih baik dan mempermudah proses pencatatan bagi usaha Bolen Menul.

## Fitur Pelanggan
- Pilih tanggal dengan batas otomatis minimal H+2.
- Pilih varian, kemasan 6 dan 10, dan jumlah box, dengan total harga langsung tampil.
- Pilih ambil di outlet atau delivery.
- Pilih pembayaran cash atau QRIS, dibayar saat barang diterima.
- Setelah memesan, pelanggan dapat kode pesanan dan tombol konfirmasi lewat WhatsApp.

## Fitur Admin
- Input pesanan manual untuk pembeli yang datang atau telepon.
- Admin boleh memilih tanggal mulai hari ini dan memakai kemasan isi 4 untuk souvenir.
- Daftar pesanan, ubah status pesanan dan status bayar, serta tombol chat WhatsApp ke pelanggan.
- Rekap produksi per tanggal, varian, dan kemasan.
- Rekap penjualan berisi
 omzet, sudah atau belum dibayar, cash dibanding QRIS, dan ambil dibanding delivery.
- Kedua rekap bisa diunduh ke Excel, jadi pembukuan manual bisa digantikan.
- Halaman Pengaturan untuk ganti harga, nomor WhatsApp outlet, ongkir, minimal hari PO, dan kuota produksi per hari.

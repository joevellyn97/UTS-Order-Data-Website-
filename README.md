# UTS-Order-Data-Website-
This website was created to fulfill a final project requirement for an advanced database course. With this website, it is hoped that the disorganized data from the manual record keeping system can now be better organized and make record keeping easier for the Bolen Menul business.
## Fitur Pelanggan
- Pilih tanggal dengan batas otomatis minimal H+2.
- Pilih varian, kemasan 6 dan 10, dan jumlah box, dengan total harga langsung tampil.
- Pilih ambil di outlet atau delivery.
- Pilih pembayaran cash atau QRIS, dibayar saat barang diterima.
- Setelah memesan, pelanggan dapat kode pesanan dan tombol konfirmasi lewat WhatsApp.

## Fitur Admin
- Input pesanan manual untuk pembeli yang datang atau telepon. Admin boleh memilih tanggal mulai hari ini dan memakai kemasan isi 4 untuk souvenir.
- Daftar pesanan, ubah status pesanan dan status bayar, serta tombol chat WhatsApp ke pelanggan.
- Rekap produksi per tanggal, varian, dan kemasan.
- Rekap penjualan: omzet, sudah atau belum dibayar, cash dibanding QRIS, dan ambil dibanding delivery.
- Kedua rekap bisa diunduh ke Excel, jadi pembukuan manual Anda bisa digantikan.
- Halaman Pengaturan untuk ganti harga, nomor WhatsApp outlet, ongkir, minimal hari PO, dan kuota produksi per hari.
